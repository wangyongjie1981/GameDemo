# 打砖块 Breakout

一个现代风格的经典打砖块游戏，使用纯 HTML5 Canvas + JavaScript 实现。

![Game Preview](https://img.shields.io/badge/Game-Breakout-4ecdc4?style=for-the-badge)
![HTML5](https://img.shields.io/badge/HTML5-Canvas-orange?style=flat-square)
![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow?style=flat-square)

## 🎮 游戏特性

- 🧱 6行彩色砖块，共48块
- ❤️ 3条生命
- 🎯 得分系统（每块砖10分）
- 🏆 胜利/失败界面
- 🔄 一键重新开始
- 📱 支持键盘、鼠标和触屏控制

## 🕹️ 操作方式

| 控制方式 | 操作 |
|---------|------|
| 键盘 | `←` `→` 或 `A` `D` 移动挡板 |
| 鼠标 | 移动鼠标控制挡板位置 |
| 触屏 | 滑动屏幕控制挡板 |
| 开始/重开 | 点击按钮 或 `空格键` / `回车键` |

## 🚀 本地运行

### 方式一：直接打开
直接在浏览器中打开 `index.html` 文件即可游玩。

### 方式二：本地服务器
```bash
# 使用 Python 3
python -m http.server 8000

# 使用 Node.js (需安装 http-server)
npx http-server

# 使用 PHP
php -S localhost:8000
```
然后访问 `http://localhost:8000`
